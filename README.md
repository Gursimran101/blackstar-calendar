# Blackstar Calendar

A polished Google Calendar-style static app branded for Blackstar. Events and reminders are stored locally in the browser, so meetings survive refreshes and closed tabs on the same device.

## Local Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
